# sigil-agora-post

X や Threads のような SNS（ソーシャルネットワーキングサービス）を提供する、Sigil 部品群のアプリケーション層の部品。agora＝古代ギリシャで人々が集い、語り合った広場を名前の由来とし、post＝投稿を示す。

## 役割

- 投稿、フォロー関係（ソーシャルグラフ）、タイムライン／フィード、反応（いいね等）、通知を担う
- 役割は「人と投稿のつながり」に一つに絞る。コメント（投稿への返信）は投稿と地続きのため初期範囲に含める。DM・検索・トレンド・収益化は初期範囲に入れず、後段で扱う
- 部品群を「使う側」に立つアプリケーション層の部品の2件目（1件目は sigil-lantern-stream）。疎結合な部品の組み合わせで本格的なサービスが作れることの実証（ドッグフーディング）の範囲を、映像の公開から人と人のつながりへ広げる
- 将来、所有者の VTuber キャラクター「シジ」の発信の場になりうる

## 既存部品との分担

- 認証: アカウントは sigil-rune-auth
- 保存: 投稿・フォロー関係・反応は sigil-db
- 通知の配送: sigil-herald-queue へ投入し、sigil-raven-mail 等が配送する。本部品は通知の発生まで
- メディアの配信: 画像等のファイルは sigix が静的配信する
- 入口の経路: sigil-atlas-dns → sigil-shield-tls → sigil-aegis-waf → sigix の主経路に乗る
- 監視: sigil-argus-observe

## 状態

計画・リポジトリ作成済み（2026-11-23 に採用決定）。実装はこれからで、着手時は ADR 起草の段から始める。依存する部品（sigix、rune-auth、herald-queue、sigil-db 等）の実装が前提になるため、着手時期は実装順の再考で決める。
